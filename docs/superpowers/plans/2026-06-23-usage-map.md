# IECentral Usage Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A super-admin-only `/usage` dashboard showing login engagement plus a user × feature heatmap, fed by new lightweight per-user feature-usage tracking.

**Architecture:** A single `featureUsage` rollup table holds daily per-user, per-feature counters. A client shell hook maps each route (+ a couple of explicit events) to a `featureKey` and upserts a counter via `recordUsage`. A super-admin query aggregates the table for the dashboard.

**Tech Stack:** Next.js 15 (App Router), Convex, React 19, recharts (already a dep), Tailwind v4.

## Global Constraints

- Dashboard + `getUsageSummary` are **super-admin only** (`requireRole(ctx, userId, ["super_admin"])`).
- `recordUsage` records the **caller's own** usage; gate = active user only (`requireMinTier(ctx, userId, 0)` — exists + `isActive`).
- Day bucket = **America/New_York** date string `"YYYY-MM-DD"` via `Intl.DateTimeFormat("en-CA", { timeZone: "America/New_York" })`.
- Convex **queries must be deterministic** — never call `Date.now()` in a query; the dashboard passes an explicit `startDate` string.
- iOS-admin aesthetic (system font, grouped cards, accent `#007AFF`); no editorial pull-quotes.
- Verification: pure functions get a node test; Convex/React get `npx tsc --noEmit` (`-p convex/tsconfig.json` and `-p tsconfig.json`); UI gets a manual check. No JS test runner exists in this repo.
- Commit after each task; push deploys Convex + Vercel from `origin/main`.

```ts
// lib/usageFeatures.ts
export type FeatureRef = { featureKey: string; section: string; label: string };

// Public / unauthenticated routes we never track.
export const SKIP_PREFIXES = ["/login", "/join", "/report", "/public", "/change-password", "/exit-survey"];

// Top-level route prefix -> { key, section, label }. Longest prefix wins.
const SECTIONS: Array<{ prefix: string; key: string; section: string; label: string }> = [
  { prefix: "/reports", key: "reports", section: "Reports", label: "Reports" },
  { prefix: "/email", key: "email", section: "Email", label: "Email" },
  { prefix: "/documents", key: "dochub", section: "Doc Hub", label: "Doc Hub" },
  { prefix: "/personnel", key: "personnel", section: "Personnel", label: "Personnel" },
  { prefix: "/applications", key: "applications", section: "Recruiting", label: "Applications (ATS)" },
  { prefix: "/time-clock", key: "timeClock", section: "Time", label: "Time Clock" },
  { prefix: "/time-off", key: "timeOff", section: "Time", label: "Time Off" },
  { prefix: "/payroll", key: "payroll", section: "Payroll", label: "Payroll" },
  { prefix: "/scanner", key: "scanners", section: "Scanners", label: "Scanners" },
  { prefix: "/equipment", key: "equipment", section: "Equipment", label: "Equipment" },
  { prefix: "/meetings", key: "meetings", section: "Meetings", label: "Meetings" },
  { prefix: "/daily-log", key: "dailyLog", section: "Daily Log", label: "Daily Log" },
  { prefix: "/safety", key: "safety", section: "Safety", label: "Safety" },
  { prefix: "/dealer-rebates", key: "reports.dealerRebates", section: "Reports", label: "Dealer Rebates" },
  { prefix: "/dunlop-reporting", key: "reports.dunlop", section: "Reports", label: "Dunlop Reporting" },
  { prefix: "/settings", key: "settings", section: "Settings", label: "Settings" },
];

// Personnel sub-areas (HR breakout) — checked before the generic /personnel section.
const PERSONNEL_SUB: Array<{ match: RegExp; key: string; label: string }> = [
  { match: /\/reviews?(\/|$)/, key: "personnel.reviews", label: "Reviews" },
  { match: /\/write-?ups?(\/|$)/, key: "personnel.writeUps", label: "Write-ups" },
];

// Report-type labels for the ?type= breakout.
const REPORT_TYPES: Record<string, string> = {
  inventory: "Inventory", "dealer-rebates": "Dealer Rebates", dunlop: "Dunlop",
  "wtd-commission": "WTD Commission", sales: "Sales", turnover: "Turnover",
  equipment: "Equipment", "exit-interviews": "Exit Interviews",
};

export function resolveFeature(pathname: string, search = ""): FeatureRef | null {
  if (!pathname || pathname === "/") return { featureKey: "dashboard", section: "Dashboard", label: "Dashboard" };
  if (SKIP_PREFIXES.some((p) => pathname === p || pathname.startsWith(p + "/") || pathname.startsWith(p + "?"))) return null;

  // Reports with a ?type= → break out the report type.
  if (pathname === "/reports" || pathname.startsWith("/reports/")) {
    const type = new URLSearchParams(search).get("type");
    if (type) {
      const label = REPORT_TYPES[type] || type.replace(/-/g, " ");
      return { featureKey: `reports.${type}`, section: "Reports", label: `${label} Report` };
    }
    return { featureKey: "reports", section: "Reports", label: "Reports" };
  }

  // Personnel sub-areas before the generic section.
  if (pathname.startsWith("/personnel")) {
    for (const s of PERSONNEL_SUB) if (s.match.test(pathname)) return { featureKey: s.key, section: "Personnel", label: s.label };
  }

  // Longest matching section prefix.
  const hit = SECTIONS.filter((s) => pathname === s.prefix || pathname.startsWith(s.prefix + "/"))
    .sort((a, b) => b.prefix.length - a.prefix.length)[0];
  if (hit) return { featureKey: hit.key, section: hit.section, label: hit.label };

  // Untracked-but-authenticated route: bucket under "Other" by first segment.
  const seg = pathname.split("/").filter(Boolean)[0] || "other";
  return { featureKey: `other.${seg}`, section: "Other", label: seg };
}
```

### Task 3: `recordUsage` mutation + `nyDate` helper (`convex/usage.ts`)

**Files:**
- Create: `convex/usage.ts`

**Interfaces:**
- Consumes: `featureUsage` table; `requireMinTier` from `./authGuards`.
- Produces: `recordUsage` mutation `{ requestingUserId: Id<"users">, featureKey, section, label }`; internal `nyDate(ts)`.

- [ ] **Step 1: Write the mutation**

```ts
// convex/usage.ts
import { mutation, query } from "./_generated/server";
import { v } from "convex/values";
import { requireMinTier, requireRole } from "./authGuards";

export function nyDate(ts: number): string {
  return new Intl.DateTimeFormat("en-CA", { timeZone: "America/New_York" }).format(new Date(ts));
}

export const recordUsage = mutation({
  args: {
    requestingUserId: v.id("users"),
    featureKey: v.string(),
    section: v.string(),
    label: v.string(),
  },
  handler: async (ctx, args) => {
    await requireMinTier(ctx, args.requestingUserId, 0); // any active user; records own usage
    const user = await ctx.db.get(args.requestingUserId);
    const now = Date.now();
    const date = nyDate(now);
    const existing = await ctx.db
      .query("featureUsage")
      .withIndex("by_user_feature_date", (q) =>
        q.eq("userId", args.requestingUserId).eq("featureKey", args.featureKey).eq("date", date),
      )
      .first();
    if (existing) {
      await ctx.db.patch(existing._id, { count: existing.count + 1, lastAt: now });
    } else {
      await ctx.db.insert("featureUsage", {
        userId: args.requestingUserId,
        userName: user?.name || "Unknown",
        featureKey: args.featureKey,
        section: args.section,
        label: args.label,
        date,
        count: 1,
        lastAt: now,
      });
    }
    return null;
  },
});
```

```ts
// lib/useUsageTracking.ts
"use client";
import { useEffect, useRef } from "react";
import { usePathname, useSearchParams } from "next/navigation";
import { useMutation } from "convex/react";
import { api } from "@/convex/_generated/api";
import { useAuth } from "@/app/auth-context";
import { resolveFeature } from "@/lib/usageFeatures";

const DEDUPE_MS = 30_000;

export function UsageTracker() {
  const pathname = usePathname();
  const searchParams = useSearchParams();
  const { user } = useAuth();
  const record = useMutation(api.usage.recordUsage);
  const lastByKey = useRef<Map<string, number>>(new Map());

  useEffect(() => {
    if (!user?._id) return;
    const ref = resolveFeature(pathname, searchParams?.toString() ? `?${searchParams.toString()}` : "");
    if (!ref) return;
    const now = Date.now();
    const last = lastByKey.current.get(ref.featureKey) || 0;
    if (now - last < DEDUPE_MS) return;
    lastByKey.current.set(ref.featureKey, now);
    void record({ requestingUserId: user._id, featureKey: ref.featureKey, section: ref.section, label: ref.label })
      .catch(() => { /* usage tracking is best-effort; never surface errors */ });
  }, [pathname, searchParams, user?._id, record]);

  return null;
}
```

```ts
// convex/usage.ts — append
export const getUsageSummary = query({
  args: { requestingUserId: v.id("users"), startDate: v.string() },
  handler: async (ctx, args) => {
    await requireRole(ctx, args.requestingUserId, ["super_admin"]);

    const rows = await ctx.db
      .query("featureUsage")
      .withIndex("by_date", (q) => q.gte("date", args.startDate))
      .collect();
    const users = await ctx.db.query("users").filter((q) => q.eq(q.field("isActive"), true)).collect();

    // Per-feature totals.
    const featTotals = new Map<string, { label: string; section: string; total: number }>();
    // Per-user totals + per-user-per-feature.
    const userTotals = new Map<string, number>();
    const userFeat = new Map<string, Map<string, number>>();
    const loginsByDay = new Map<string, number>();
    const activeUserIds = new Set<string>();

    for (const r of rows) {
      activeUserIds.add(r.userId);
      const f = featTotals.get(r.featureKey) || { label: r.label, section: r.section, total: 0 };
      f.total += r.count; featTotals.set(r.featureKey, f);
      userTotals.set(r.userId, (userTotals.get(r.userId) || 0) + r.count);
      const uf = userFeat.get(r.userId) || new Map(); uf.set(r.featureKey, (uf.get(r.featureKey) || 0) + r.count); userFeat.set(r.userId, uf);
      if (r.featureKey === "login") loginsByDay.set(r.date, (loginsByDay.get(r.date) || 0) + r.count);
    }

    const topFeatures = [...featTotals.entries()]
      .map(([featureKey, v2]) => ({ featureKey, label: v2.label, section: v2.section, total: v2.total }))
      .sort((a, b) => b.total - a.total);

    const heatmapFeatures = topFeatures.filter((f) => f.featureKey !== "login").slice(0, 20)
      .map((f) => ({ featureKey: f.featureKey, label: f.label }));
    const heatKeys = new Set(heatmapFeatures.map((f) => f.featureKey));

    const nameOf = new Map(users.map((u) => [u._id as string, u.name || u.email || "Unknown"]));
    const lastLoginOf = new Map(users.map((u) => [u._id as string, u.lastLoginAt]));

    const perUser = [...userTotals.entries()].map(([userId, total]) => {
      const uf = userFeat.get(userId)!;
      const top = [...uf.entries()].filter(([k]) => k !== "login")
        .map(([k, count]) => ({ label: featTotals.get(k)?.label || k, count }))
        .sort((a, b) => b.count - a.count).slice(0, 3);
      return { userId, name: nameOf.get(userId) || "Unknown", lastLoginAt: lastLoginOf.get(userId), total, top };
    }).sort((a, b) => b.total - a.total);

    const heatmapRows = perUser.map((u) => {
      const uf = userFeat.get(u.userId)!;
      const counts: Record<string, number> = {};
      for (const k of heatKeys) counts[k] = uf.get(k) || 0;
      return { userId: u.userId, name: u.name, counts };
    });

    const dormantUsers = users.filter((u) => !activeUserIds.has(u._id as string))
      .map((u) => ({ _id: u._id, name: u.name || u.email || "Unknown", lastLoginAt: u.lastLoginAt }));

    return {
      activeUserCount: activeUserIds.size,
      dormantUsers,
      loginsByDay: [...loginsByDay.entries()].map(([date, count]) => ({ date, count })).sort((a, b) => a.date.localeCompare(b.date)),
      topFeatures: topFeatures.filter((f) => f.featureKey !== "login"),
      perUser,
      heatmap: { features: heatmapFeatures, rows: heatmapRows },
    };
  },
});
```
